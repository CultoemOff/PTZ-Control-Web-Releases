# PTZ Control Web — Releases

Repositório público de distribuição do **PTZ Control Web — by Culto em Off**.

O código-fonte do aplicativo não é distribuído neste repositório. Aqui ficam apenas os instaladores públicos e os arquivos de verificação.

## Download para Windows

Baixe sempre a versão mais recente em:

https://github.com/CultoemOff/PTZ-Control-Web-Releases/releases/latest

Na seção **Assets**, escolha:

- `PTZ-Control-Web-Setup.exe`
- `SHA256SUMS.txt` — hash SHA-256 para verificação do instalador

## Como abrir o controle

Após instalar, o servidor local do PTZ Control Web fica disponível em:

`http://127.0.0.1:8765/obs`

Esse mesmo endereço pode ser usado no navegador e no Browser Dock do OBS Studio.
